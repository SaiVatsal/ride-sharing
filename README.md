# Project 31: Urban Ride-Sharing & Fleet Telemetry (VoltCab)

An on-demand urban mobility and chauffeur dispatch platform built with React 18, Vite, TailwindCSS, and Zustand.

## Features
- **Yellow-and-Black Cab Theme**: High-contrast urban aesthetic (`#0a0a0a`, `#eab308`, `#facc15`) with Space Grotesk and JetBrains Mono typography.
- **Interactive Full-Bleed Map Canvas**: Real-time road grid visualization with live driver coordinate updates, pickup pins, and destination beacons.
- **Fleet Class Tiers**: Economy Sedan, Volt Green EV, Black Executive Chauffeur, and Van XL with dynamic fare estimation.
- **Integrated In-App Live Chat**: Real-time two-way messaging between passenger and chauffeur.
- **Driver Simulator Cockpit**: Advance trip status from dispatch to pickup, in-transit, and destination arrival.
- **Ride History & Itemized Receipts**: Comprehensive trip archive with post-ride tipping and 5-star feedback rating.

## Getting Started
```bash
npm install
npm run dev
```
